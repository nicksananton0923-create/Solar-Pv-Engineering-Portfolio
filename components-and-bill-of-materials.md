# Components and Bill of Materials — Solar PV Engineering Portfolio

This framework is documentation only. The BOM for a specific project depends on the module and inverter selection. Typical components:

| Component | Quantity basis | Typical specifications |
|---|---|---|
| PV modules | Per DC capacity | 400–550 Wp, 72/144-cell or 96-cell |
| String inverter | Per AC capacity | 97–98 % European efficiency |
| Central inverter (large projects) | Per AC capacity | 98 % European efficiency |
| DC cabling | Per string length | PV wire, 1500 V DC rated, UV-resistant |
| AC cabling | Per inverter-to-transformer distance | Per local code |
| Transformer | Per project size | Per local grid voltage |
| Mounting structure | Per module count | Galvanised steel or aluminium |
| Earthing | Per array area | Per IEC 62548 / local code |
| Surge protection | Per inverter | Per IEC 62305 / local code |
| Monitoring system | Per project | Per vendor |

Refer to the project-specific BOM for actual quantities and ratings.
