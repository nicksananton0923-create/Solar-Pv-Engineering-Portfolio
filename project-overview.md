# Project Overview — Solar PV Engineering Portfolio

## Summary

This project provides an engineering documentation framework for ground-mounted solar PV projects. It includes templates for module and inverter registers, illustrative calculations for system sizing and energy yield, and procedural documentation aligned with IEC 62548 (PV array design) and IEC 62446 (commissioning).

## Important Disclaimer

All calculations in this framework are **illustrative**, using standard public reference values (STC, NOCT, temperature coefficients). They are not approved engineering designs. A real project requires engineering review by a competent solar PV engineer and compliance with local electrical codes and grid-connection requirements.

## Audience

Solar PV project engineers, EPC (Engineering, Procurement, Construction) contractors, and project developers who need a consistent documentation framework for ground-mounted PV projects.

## Positioning

This portfolio represents an Electrical Technology Student's documentation work. It does not claim to be a professional engineering design, and the user does not claim to hold a professional engineering qualification.
