# Site Assessment Methodology — Solar PV Engineering Portfolio

## Overview

This document describes the methodology for assessing a candidate site for a ground-mounted solar PV project.

## Step 1 — Land Suitability

Verify the following:

- **Land use classification:** the site must be suitable for solar PV use per local planning regulations.
- **Land ownership:** the developer must have the right to use the land for solar PV.
- **Topography:** the site should be relatively flat (slope < 5 %) to minimise earthworks.
- **Soil bearing capacity:** the soil must be able to support the mounting structure foundations (geotechnical survey required).
- **Drainage:** the site must not be prone to flooding.
- **Access:** the site must be accessible for construction equipment and O&M.

## Step 2 — Solar Resource Assessment

- Obtain the local solar resource (kWh/m²/year) from a reputable solar atlas (e.g. PVGIS, SolarGIS, NASA POWER).
- For bankable projects, purchase a TMY (Typical Meteorological Year) file from a meteorological data provider.
- Verify the resource with on-site measurement (pyranometer) for at least 12 months for utility-scale projects.

## Step 3 — Shading Assessment

- Perform a horizon scan (using a Sun path diagram or a solar survey instrument) to identify shading objects (hills, buildings, trees).
- Calculate the shading loss using a PVsyst-style simulation.

## Step 4 — Grid Connection Assessment

- Identify the nearest grid connection point.
- Verify the grid voltage and capacity.
- Consult the local grid operator for connection requirements.
- Obtain a connection offer (or letter of intent) before finalising the project.

## Step 5 — Environmental Impact Assessment

- Verify whether an EIA is required (typically required for projects above a certain size, e.g. 5 MW in many jurisdictions).
- If required, commission an EIA from an approved consultant.

## Step 6 — Permitting Assessment

- Verify the required permits (planning, environmental, building, electrical, grid connection).
- Verify the AHJ for each permit.
- Estimate the permitting timeline.

## Step 7 — Financial Feasibility

- Estimate the project CAPEX (modules, inverters, BOS, EPC, grid connection, permitting).
- Estimate the project OPEX (O&M, insurance, land lease, management).
- Estimate the project revenue (energy sale, tariff, PPA).
- Calculate the LCOE (Levelised Cost of Energy), payback period, and IRR (Internal Rate of Return).

## Outputs

A site assessment report containing:

- Site description
- Solar resource assessment
- Shading assessment
- Grid connection assessment
- Environmental impact assessment summary
- Permitting plan
- Financial feasibility summary
- Recommendation (proceed / do not proceed / further study required)
