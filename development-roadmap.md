# Development Roadmap — Solar PV Engineering Portfolio

## v1.0 (current)

- CSV templates for module and inverter registers
- Illustrative calculations for system sizing, string configuration, energy yield
- Procedural documentation aligned with IEC 62548 / 62446
- Fictional sample project

## v1.1 (planned)

- Add Python script for energy yield calculation using TMY data
- Add structural design templates for mounting structures
- Add a financial model template (LCOE, payback, IRR)

## v2.0 (planned)

- Add grid-connection study templates
- Add environmental impact assessment templates
- Add O&M manual template

## v3.0 (future)

- Migrate to a database-backed web application for project management
