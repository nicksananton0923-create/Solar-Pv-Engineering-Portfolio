# System Architecture — Solar PV Engineering Portfolio

## System Architecture

A typical ground-mounted PV system consists of:

- **PV array:** groups of series-connected modules forming strings
- **DC combiner:** combines parallel strings and provides fusing
- **Inverter:** converts DC to AC
- **AC switchgear:** isolates and protects the AC side
- **Transformer (if needed):** steps up AC voltage for grid connection
- **Earthing system:** functional and protective earthing
- **Surge protection:** lightning and surge protection
- **Monitoring system:** tracks generation and performance

## Standards Alignment

- IEC 61215: PV module design qualification
- IEC 62109: Inverters — safety
- IEC 60364-7-712: Electrical installations of buildings — solar PV power supply systems
- IEC 62305: Lightning protection
