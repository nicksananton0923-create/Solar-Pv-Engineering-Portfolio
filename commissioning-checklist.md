# Commissioning Checklist — Solar PV Engineering Portfolio

## Overview

This document is a commissioning checklist aligned with IEC 62446 (Grid-connected PV systems — minimum requirements for system documentation, commissioning tests, and inspection).

## Pre-Energisation Inspection

### Mechanical

- [ ] Modules installed per design drawings
- [ ] Module mounting torque verified
- [ ] Cable management correct
- [ ] Earthing connections verified
- [ ] Warning labels affixed

### Electrical — DC side

- [ ] String polarity verified
- [ ] String Voc measured at STC-equivalent conditions and matches design (±5 %)
- [ ] String Isc measured and matches design (±10 %)
- [ ] Insulation resistance test (Megger) of DC strings performed (≥ 40 MΩ·km² typical)
- [ ] DC isolators operate correctly
- [ ] DC SPDs installed

### Electrical — AC side

- [ ] AC cable insulation verified
- [ ] AC isolators operate correctly
- [ ] AC SPDs installed
- [ ] Earthing system resistance measured and within specification
- [ ] Inverter AC voltage and frequency match grid

### Documentation

- [ ] As-built drawings available
- [ ] Module serial numbers recorded (per string)
- [ ] Inverter serial numbers recorded
- [ ] Cable test certificates available
- [ ] Earthing test certificates available

## Energisation Tests

### DC Side

- [ ] String Voc at inverter terminals matches design
- [ ] String Isc at inverter terminals matches design (use caution)
- [ ] DC isolator operation confirmed

### Inverter Startup

- [ ] Inverter boots without fault
- [ ] Inverter connects to grid (verify grid parameters in spec)
- [ ] Inverter MPPT active (DC voltage within MPPT range)
- [ ] Inverter AC output within specification

### AC Side

- [ ] AC voltage at inverter terminals within specification
- [ ] AC power flow direction correct (export)
- [ ] Export meter registers correctly

### Performance Verification

- [ ] Irradiance sensor reads within specification
- [ ] Module temperature sensor reads within specification
- [ ] Inverter performance ratio (measured) ≥ 95 % of expected
- [ ] No fault alarms

## Handover Documentation

- [ ] Commissioning report signed by the commissioning engineer
- [ ] Operating manual provided
- [ ] O&M manual provided
- [ ] Warranty certificates provided (modules, inverters, BOS)
- [ ] As-built drawings provided
- [ ] Module and inverter registers provided
- [ ] Spare parts list provided

## Standards Alignment

This checklist is aligned with IEC 62446-1:2016 (Grid-connected PV systems — Minimum requirements for system documentation, commissioning tests, and inspection). Local codes may require additional tests.
